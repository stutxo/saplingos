# Security policy

Sapling's program-controlled wallet integration is experimental. Local tests do
not establish production enclave attestation or an independent cryptographic
review. Do not assume the upstream Bark team's support or security review
covers this fork's changes.

Do not disclose exploitable issues, wallet secrets, witness data, or private
recovery exports in public issues or chat.

For Sapling-specific issues, use the repository's private vulnerability
reporting option if available, or establish a private channel with the
repository owner before sharing exploit details. No dedicated Sapling security
email address is declared here.

For vulnerabilities affecting upstream Bark independently of Sapling, follow
[upstream's security policy](https://gitlab.com/ark-bitcoin/bark/-/blob/master/SECURITY.md).
The upstream contact is `security@second.tech`; it is not presented as the
maintainer of this fork.
